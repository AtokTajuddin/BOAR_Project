Scope

What this page can and cannot prove

Static heuristics

This is a source-level triage tool, not a proof. It has no full dataflow, points-to, or interprocedural analysis. Use ASan, UBSan, Valgrind, and fuzzing to confirm a finding.

No native execution

GitHub Pages serves static files only. The browser cannot run GDB, execute a target binary, discover a live offset, or generate a working exploit. Those stay in the local CLI.

Private by default

The analyzer is plain JavaScript. Source is read with the File API and never uploaded. The page needs no backend, account, or network request after loading.
